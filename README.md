# 🛍️ Myntra Sales Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Myntra Sales Analysis Dashboard** developed using **Power BI** to analyze sales performance, customer purchasing behavior, product trends, and business KPIs. The dashboard helps stakeholders make data-driven decisions by providing actionable insights into revenue, orders, categories, brands, and regional sales performance.

---

## 🚀 Project Objectives

- Analyze overall sales performance.
- Identify top-performing brands and products.
- Track revenue trends across categories.
- Evaluate customer purchasing patterns.
- Discover state-wise sales distribution.
- Monitor key business KPIs for decision-making.
